# Project language

Use English for the primary README, new documentation, code comments, default user-facing text, commit messages, and pull request descriptions.

Keep explicitly localized files, such as `README.pt-BR.md` and `locales/pt-BR.json`, in their target language. English is the primary language of this public project; Portuguese remains an optional translation.

# Public repository privacy

This repository is public. Keep code, documentation, examples, and commit messages generic and useful to all users, without instructions tailored to the repository owner's installation.

Never publish credentials, private configuration, real health readings, personal device names or network addresses, machine-specific paths, logs, backups, or unreviewed photos. Use clearly synthetic fixtures and examples instead.

Before every commit or push, review the exact staged changes and commit metadata for sensitive information. Stage explicit file paths and keep local data excluded. Use the existing GitHub noreply commit email unless a different public identity is explicitly requested.
